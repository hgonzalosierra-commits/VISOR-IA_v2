# HIDRO-VISION AI

Visor de comparación de ortofotos y videos del Tramo 03, margen izquierda, 0+000 a 1+000.

## Ver el aplicativo

Abrir `docs/index.html` localmente, o activar GitHub Pages desde Settings → Pages → Deploy from a branch → main → /docs → Save.

La página funciona con archivos estáticos, sin servidor de datos ni cuentas de usuario. El navegador de cada revisor guarda sus propios dictámenes; exportar JSON para compartirlos.

## Contenido

Ortofotos enero/julio de 2026, videos enero/agosto, 11 pares de ortofotos cada 100 m y 22 referencias de video seleccionadas por posición GPS del dron. La progresiva del dron no localiza todo el terreno de la vista oblicua. La revisión de candidatos se limita a una franja conservadora del cuerpo del dique: 11 candidatos en el primer sector y 3 en el segundo. El contexto fluvial se interpreta por separado.

Son resultados exploratorios. No se han confirmado daños, depósitos nuevos o socavación. No se incluye vegetación como partida de obra. Autores: pendientes.

## Archivos de esta publicación

Incluye el visor, imágenes reducidas, fotogramas y tablas/GeoJSON de resultados. Excluye MP4, SRT originales, GeoTIFF, DWG, planos, dependencias y documentos preliminares con recuentos anteriores. Los resultados conservan coordenadas y la localización de la obra: al publicar este repositorio y su sitio, ese contenido será accesible.

Los archivos originales permanecen en el proyecto local. Esta carpeta es una exportación del visor, no todo el entorno de procesamiento geoespacial.
